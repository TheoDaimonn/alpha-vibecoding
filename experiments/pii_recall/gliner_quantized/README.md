# GLiNER: квантование и измерения

CPU Mac ARM64, ONNX Runtime 1.23.2, один поток. 384 dev-документа, выборка по источникам пропорционально их долям, seed 20260923. Индексы и SHA256 корпуса сохранены в JSON. Это подвыборка, не полный dev и не независимый тест.

Latency: полный детектор с токенизацией, оконной обработкой и декодированием, batch=1. 3 прогрева + 20 коротких синтетических запросов около 130 символов. HTTP и очередь API не входят. Ноутбук не был выделенной тестовой машиной; интервалы доверия не оценивались.

## Что именно квантовано

- INT8: ONNX Runtime dynamic QInt8 для MatMul/Gemm/Gather, per_channel=False. Остальные операторы остаются FP32. Это один конкретный рецепт; другие способы требуют отдельного замера.
- FP8 = E4M3FN, BF8 трактуется как E5M2 (не BF16). По 49 двумерных/многомерных весов размером >=1024 элементов хранятся в float8 с одной шкалой на тензор. Перед вычислением Cast + Mul восстанавливают FP32. Активации и вычисление — FP32; оптимизатор может раскрывать константы при загрузке, поэтому уменьшение файла не гарантирует уменьшение RAM.
- Нативные MatMul FP8/E5M2 не исполняются текущим CPU-пайплайном. Минимальная проверка записана в float8_support.json; соответствующую нативную latency измерить здесь нельзя.
- Пороги thresholds.json, метки и выборка одинаковы для всех вариантов. Метрики — exact typed spans до фильтра API. Ранее полученные метрики других моделей на полном dev нельзя напрямую сравнивать с этой подвыборкой.

## Вывод

INT8 ускорил ONNX относительно FP32 примерно в 2.6 раза по p50, но recall снизился на 3.31 п.п. Float8-хранение почти сохранило качество, однако аппаратного ускорения на этом CPU не даёт. В предыдущем отдельном замере PyTorch FP32 давал p50 около 83 мс: превосходство INT8 над исходным PyTorch не установлено.

## Воспроизведение

`HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python scripts/benchmark_gliner_quantized.py --variant int8` (варианты: fp32/int8/fp8/bf8). Веса: artifacts/gliner-onnx/. Зависимости экспорта: onnx, onnxruntime, ml_dtypes; версии runtime сохранены в JSON.

Форматы: [ONNX float8](https://onnx.ai/onnx/technical/float8.html). INT8: [ONNX Runtime quantization](https://onnxruntime.ai/docs/performance/model-optimizations/quantization.html).
